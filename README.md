## ✨ Возможности

### Для покупателей
- **Каталог** товаров с разбивкой по категориям (хвойные, лиственные, плодовые и т.д.)
- **Поиск** по названию товара (поддержка кириллицы)
- **Сортировка** по цене (дешевле/дороже)
- **Пагинация** — 6 товаров на странице
- **Корзина** с возможностью изменения количества (+/−)
- **Избранное** — добавление товаров в список любимых
- **Промокоды** — применение скидочных купонов
- **Отзывы** с оценкой 1–5 звёзд (один отзыв на товар от пользователя)
- **Оформление заказа** с выбором пункта самовывоза (15 точек по Уфе) и способа оплаты
- **Личный кабинет** — редактирование данных и история заказов
- **Регистрация и вход** по email + пароль

### Безопасность
- Валидация пароля: минимум 8 символов, заглавная, строчная, цифра, спецсимвол
- Уникальность email
- Защита от CSRF
- Только авторизованные пользователи могут оставлять отзывы и добавлять в избранное

### Для администратора
- Полнофункциональная админ-панель Django
- Управление товарами, категориями, заказами, отзывами, купонами, пользователями
- Загрузка фотографий товаров

## 🚀 Установка и запуск

### Требования
- Python 3.11 или выше
- Git

### Шаги установки

**1. Клонировать репозиторий:**

```bash
git clone https://github.com/ВАШ_ЛОГИН/django-shop.git
cd django-shop
```

**2. Создать виртуальное окружение:**

Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

Linux/Mac:
```bash
python3 -m venv venv
source venv/bin/activate
```

**3. Установить зависимости:**

```bash
pip install -r requirements.txt
```

**4. Применить миграции:**

```bash
python manage.py migrate
```

**5. Создать суперпользователя:**

```bash
python manage.py createsuperuser
```

Введите логин, email и пароль.

**6. Запустить сервер:**

```bash
python manage.py runserver
```

Открыть в браузере:
- Сайт: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/

## 🗄 Описание моделей

### Category — Категории
- `name` — название
- `slug` — URL-имя

### Product — Товары
- `category` — категория (FK)
- `name`, `slug`, `description`
- `image` — фото
- `price` — цена
- `available` — в наличии или нет
- `created` — дата добавления

### Order — Заказы
- `user` — покупатель
- `first_name`, `phone` — данные (берутся из профиля)
- `address` — пункт самовывоза (15 точек)
- `comment` — комментарий
- `payment_method` — способ оплаты (наличные/карта при получении)
- `paid` — статус оплаты
- `created` — дата создания
- `get_order_code()` — код заказа (например, ORD-2026-0034)

### OrderItem — Позиции в заказе
- `order` — заказ
- `product` — товар
- `price`, `quantity`

### Profile — Профиль пользователя
- `user` — связь с User (OneToOne)
- `phone` — телефон

### Favorite — Избранное
- `user`, `product`, `created`

### Review — Отзывы
- `product`, `user`
- `text`, `rating` (1–5)
- Уникальная пара (product, user)

### Coupon — Купоны
- `code` — промокод
- `discount` — скидка в %
- `valid_from`, `valid_to` — срок действия
- `active`

## 🔐 Админка

После создания суперпользователя зайдите в `/admin/`. Вы можете:

- **Добавлять товары** — категория, название, цена, фото, описание
- **Управлять заказами** — отмечать как оплаченные, видеть детали
- **Создавать купоны** — задавать код, скидку, срок действия
- **Модерировать отзывы** — удалять неуместные
- **Управлять пользователями** — блокировать, давать права

### Создание тестовых данных

1. Создайте 3–5 категорий (Хвойные, Лиственные, Плодовые)
2. Добавьте 10–20 товаров с фотографиями
3. Создайте купон, например `SALE20` со скидкой 20%

## ⚠️ Возможные проблемы

### Email-уведомления (UnicodeError на Windows)
На Windows + Python 3.11 встроенный консольный backend для email падает с ошибкой `idna codec failed`. Решение в текущей версии — вывод писем напрямую через `print` в `views.py`. На реальном сервере с настроенным SMTP проблемы нет.

### Поиск кириллицы
SQLite по умолчанию не поддерживает `icontains` для русских букв. В `views.py` поиск реализован через Python-фильтрацию.

### Профили для существующих пользователей
Если добавили модель `Profile` после создания пользователей, для них нужно создать профили вручную:

```bash
python manage.py shell
```

```python
from django.contrib.auth.models import User
from shop.models import Profile
for user in User.objects.all():
    Profile.objects.get_or_create(user=user)
exit()
```
